Primary Sprint 30 goals:

A. Extend drill ledger with trusted evidence identity
- For each drill, add fields such as:
  - evidence record id
  - artifact SHA-256
  - verification status
  - trust tier / trust decision
  - source system / provider metadata
  - allowed URI prefix or trust-policy evaluation result where applicable
- Keep the representation stable and machine-reviewable.

B. Add trusted evidence validation
- Validate that:
  - the referenced evidence record exists
  - verification status is acceptable
  - trust tier satisfies the target environment policy
  - artifact hash is present and valid
  - provider-backed evidence has required provenance proof when policy requires it
  - source metadata is complete enough for audit

C. Add environment-aware trust policy
- Enforce different trust requirements for environments such as staging, prod-like, and production:
  - minimum trust tier
  - accepted verifier classes
  - allowed URI/source policies
  - freshness requirements if they differ by environment

D. Tighten waiver governance
- Waivers must become explicit governed objects with fields such as:
  - waiver id
  - authority
  - scope
  - reason
  - expiry
  - linked drills
  - non-waivable classification
- Validation must reject invalid or over-scoped waivers.

E. Add release-authority packet
- Generate a concise artifact for release authority that summarizes:
  - trusted evidence coverage by drill
  - unresolved waivers
  - non-waivable blockers
  - final release recommendation
- Keep it short, practical, and directly useful in release review.

F. Add CI/tests for trust regression
- Add tests or smoke checks for:
  - missing hash
  - unverified evidence
  - insufficient trust tier
  - invalid waiver
  - missing provider-backed provenance proof
  - acceptance failure when trust semantics are not satisfied

G. Tighten wording only where it reduces confusion
- Reduce overlap between execution, trust, acceptance, waiver, and release-authority terminology.
- Keep this bounded and secondary to the core sprint goal.
