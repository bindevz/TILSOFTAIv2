# Specification Planning Artifacts

The `spec/Sprint_*` folders are non-runtime planning materials used to steer implementation work. They are not deployment inputs, operator runbooks, release evidence, or certification artifacts.

Authoritative operator paths live under `docs/`, especially:

- `docs/staging_prodlike_certification_execution.md`
- `docs/live_certification_execution_capture.md`
- `docs/live_certification_acceptance.md`
- `docs/release_evidence_bundles.md`

When planning guidance and operator documentation differ, update the operator documentation and supporting scripts instead of treating historical sprint prompts as runtime policy.
